# AGX Validation — 2026-08-06

This record predates the repository extraction and describes the same manager,
plugins, CDI edits, and workload sources while they were carried in Ghaf PR
2095. It must be repeated after the downstream extraction is flashed.

## Functional Results

- CUDA reported 16 SMs and the manager created two 8-SM contexts.
- The standalone Green Context probe passed.
- Direct `nvidia.com/gpu=all` CDI completed a real CUDA kernel.
- Managed CDI exposed no direct GPU nodes, rejected direct CUDA, and completed
  a manager-submitted burn.
- Two concurrent 20-second burns completed successfully.
- A queued same-slot job ran after cancellation of the active job.
- A 30-minute two-slot burn completed 11,136 validated iterations on each
  slot with identical validation samples.
- Manager and GPU-VM restart counts remained zero.
- No relevant nvgpu fault, timeout, or Xid was observed.

guarantees. Thermal state, power mode, and repetition variance were not
